# CMSPlan UI v0.1

Protótipo funcional do Dashboard Executivo aplicado ao case **RNR-00579 · Boituva**.

## Executar no Mac

```bash
npm install
npm run dev
```

Abra `http://localhost:5173`.

## Impressão A4
Clique em **Imprimir A4**. O protótipo gera uma página executiva em A4 paisagem para PDF.

## Conteúdo
- Identidade CMSPlan
- Dashboard executivo Boituva
- KPIs, Curva S, disciplinas, alertas, timeline
- Painel CMS Intelligence
- Estrutura navegável dos demais módulos
